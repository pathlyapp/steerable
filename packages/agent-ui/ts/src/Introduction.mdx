# @steerable/agent-ui

> Headless React building blocks for Steerable agent UIs — 7 core components, 14 structured message cards, state/transport helpers, and 3 lifecycle hooks.

This package ships the visual surface area you need to drop a Steerable agent into a React app, plus the lifecycle hooks that own message state and tool-call status. Components are intentionally **headless**: they render through Tailwind utility classes built on a small set of `--agent-*` design tokens, so consuming apps can theme them, replace any subtree, or compose them into bespoke layouts without forking.

## What's in this Storybook

* **Components** (`@steerable/agent-ui`) — core chat primitives:
  * [`ChatPanel`](?path=/docs/components-chatpanel--docs) — foundational chat shell (`MessageList` + composer + stop button).
  * [`MessageList`](?path=/docs/components-messagelist--docs) — auto-scrolling list with a render-prop bubble.
  * [`AgentSelector`](?path=/docs/components-agentselector--docs) — segmented selector for switching the active chat agent.
  * [`ModelSelector`](?path=/docs/components-modelselector--docs) — gateway model catalog picker with reasoning effort controls.
  * [`OrchestrationPlanCard`](?path=/docs/components-orchestrationplancard--docs) — multi-step plan with per-step status.
  * [`ToolCallRenderer`](?path=/docs/components-toolcallrenderer--docs) — tool-call card with mode badges, approval, expandable args/result.
  * [`SSEStreamView`](?path=/docs/components-ssestreamview--docs) — append-only SSE event log for trace tabs and dev consoles.
* **Cards** (`@steerable/agent-ui/cards`) — 14 structured block renderers backed by `spec/blocks/*.schema.json`:
  * [`ToolExecutionCard`](?path=/docs/cards-toolexecutioncard--docs) · [`ActionSegmentCard`](?path=/docs/cards-actionsegmentcard--docs) · [`ThinkingProcessCard`](?path=/docs/cards-thinkingprocesscard--docs) · [`SummaryMessageCard`](?path=/docs/cards-summarymessagecard--docs)
  * [`OrchestrationPlanCard`](?path=/docs/cards-orchestrationplancard--docs) · [`PlanStepsCard`](?path=/docs/cards-planstepscard--docs) · [`PlanSelectorCard`](?path=/docs/cards-planselectorcard--docs) · [`ResearchPlanCard`](?path=/docs/cards-researchplancard--docs)
  * [`AskUserQuestionsCard`](?path=/docs/cards-askuserquestionscard--docs) · [`SuggestedRepliesCard`](?path=/docs/cards-suggestedrepliescard--docs) · [`SearchSourcesCard`](?path=/docs/cards-searchsourcescard--docs)
  * [`AnalysisDocumentCard`](?path=/docs/cards-analysisdocumentcard--docs) · [`QuizCard`](?path=/docs/cards-quizcard--docs) · [`CoverageReportCard`](?path=/docs/cards-coveragereportcard--docs)
* **Hooks** (`@steerable/agent-ui/hooks`) — transport-agnostic state:
  * [`useChatStream`](?path=/docs/hooks-usechatstream--docs) — owns message state and translates `SSEEvent` into `ChatMessage` mutations.
  * [`useToolCallStatus`](?path=/docs/hooks-usetoolcallstatus--docs) — derives status + mode + approval requirements for a single tool call.
  * [`useAgentSession`](?path=/docs/hooks-useagentsession--docs) — wraps create / resume / list against any session storage adapter.
* **State & Transport** (`@steerable/agent-ui/state`) & **Design Tokens** (`@steerable/agent-ui/tailwind-preset`):
  * [`MockChatStreamTransport`](?path=/docs/state-mockchatstreamtransport--docs) — scripted SSE replay transport for tests and demos.
  * [`Design Tokens`](?path=/docs/design-tokens--docs) — full `--agent-*` CSS variable reference and Tailwind v3 / v4 integration.

## Installation (consuming app)

```bash
pnpm add @steerable/agent-ui @steerable/agent-protocol react react-dom
```

If you use Tailwind v3, register the preset:

```ts
// tailwind.config.ts
import preset from '@steerable/agent-ui/tailwind-preset';
export default {
  presets: [preset],
  content: [
    './src/**/*.{ts,tsx}',
    './node_modules/@steerable/agent-ui/dist/**/*.{js,mjs}',
  ],
};
```

For Tailwind v4 callers, mirror the design tokens with `@theme` (see [Design Tokens](?path=/docs/design-tokens--docs) and `packages/agent-shell/web/src/styles/index.css` for an in-tree reference).

## Design philosophy

1. **Headless first.** Every component takes a render prop or accepts `children` for the parts a real app wants to customise (markdown rendering, mention chips, search-source pills, …). Defaults stay minimal so you never fork a component to swap one row.
2. **One token vocabulary.** All colors, radii, and animations come from `--agent-*` variables. Themes ship as CSS overrides, never as React props.
3. **Transport-agnostic hooks.** `useChatStream` and friends never speak HTTP or know which provider serves the events — they call into a transport you pass in, letting FastAPI/SSE hosts and embedded desktop sidecars share the same React UI.
4. **Mirror the framework spec.** `ChatMessage`, `ToolCall`, `ToolResult`, `SSEEvent`, `AgentSession`, and card block payloads come from `@steerable/agent-protocol`, generated from JSON schemas in `spec/`.
